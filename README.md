# ecomerceASES

## Descripción del proyecto

ecomerceASES es una página web de una librería online. El proyecto permite visualizar diferentes productos, buscar libros y filtrarlos por categoría.

Además, cuenta con un carrito de compras donde se pueden agregar productos, modificar sus cantidades y eliminarlos.

La página también tiene una sección de productos más vendidos, un formulario de contacto y páginas para iniciar sesión y registrarse.

El proyecto fue realizado como trabajo práctico utilizando HTML, CSS y JavaScript.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub

Para el diseño de la página se utilizaron principalmente **Flexbox y CSS Grid** para organizar los distintos elementos.

También se utiliza `localStorage` de JavaScript para guardar información del carrito en el navegador.

## Instrucciones para ejecutarlo

### 1. Descargar o clonar el proyecto

Desde una terminal se puede clonar el repositorio con:

git clone https://github.com/TTubi/ecomerceASES.git

### 2. Abrir el proyecto

Buscar y abrir el archivo index.html
